Inspection type/interface
The inspection contract used by the feature is:
```ts
export type Role = 'owner' | 'renter'

export type AssetType =
  | 'scooter'
  | 'bike'
  | 'apartment'
  | 'house'

export type InspectionType = 'move-in' | 'move-out'

export type InspectionStatus =
  | 'in-progress'
  | 'awaiting-confirmation'
  | 'locked'

export interface Inspection {
  id: string
  sessionCode: string
  assetType: AssetType
  assetName: string
  inspectionType: InspectionType
  status: InspectionStatus
  ownerId: string
  renterId?: string
  areas: string[]
  completedAreaIds: string[]
  createdAt: string
}
```
Required facade:
```ts
createInspection(
  input: Pick<Inspection, 'assetType' | 'assetName' | 'inspectionType'>
): Promise<Inspection>

getInspection(id: string): Promise<Inspection>

listInspections(userId: string): Promise<Inspection[]>

joinInspection(sessionCode: string): Promise<Inspection>

updateInspection(id: string, updates: Partial<Inspection>): Promise<Inspection>
```
Session-code behaviour
Exactly 6 characters.
Uppercase.
Ambiguous characters are excluded: `0/O`, `1/I`, `5/S`, `8/B`.
Codes are validated before a join request is submitted.
The mock adapter checks for a matching stored inspection.
A valid-looking but nonexistent code returns an `Inspection not found` error.
The mock adapter avoids reusing an existing session code.
Inspection areas
The mock inspection creates the areas from `INSPECTION_AREAS` based on asset type:
Scooter: Front, Left side, Right side, Rear, Handlebars, Dashboard.
Bike: Front, Left side, Right side, Rear, Handlebars, Frame.
Apartment: Entrance, Living room, Kitchen, Bedroom, Bathroom, Balcony.
House: Entrance, Living room, Kitchen, Bedrooms, Bathrooms, Staircase, Outdoor area.
